## Como apresentar

Abra no Chrome ou Edge e aperte `F` para tela cheia.

| Tecla | Ação |
|---|---|
| Seta direita, espaço ou clique à direita | Próximo slide |
| Seta esquerda ou clique à esquerda | Slide anterior |
| `F` | Tela cheia |
| `G` | Índice |
| `O` | Objeções (só no arquivo local / `apresentar.html`) |
| `Home` / `End` | Primeiro / último slide |

No celular o deck ocupa a tela inteira, rola na vertical e o HUD fica sempre visível.
